# Home feature

Home is the starter feature and initial application surface.

## Modules

- `domain`: greeting contract and model.
- `data`: internal default repository implementation.
- `navigation`: stable Home destinations.
- `ui`: Compose screen and resources.
- `test`: reusable Home repository fake for downstream tests.
